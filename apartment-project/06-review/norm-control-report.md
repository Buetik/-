# Нормоконтроль комплекта КВ108-ДП (вариант D1) — отчёт pib-norm-control

Дата: 2026-10-08. Объект: СПб, кв. 108, 69,01 м², этаж 1/4. Стадия «Р».
Проверено: `00-brief/*` (бриф, программа, D1–D23, вопросы №1–57), `01-input/measurements.json`, все слои `03-drawings/*.json`, `details.md`, `sheet-register.json`, `03-drawings/pdf/` (39 листов, album.pdf, 51 стр.), превью АР-07, АР-13, ЭМ-01, `02-concept/*`, `04-specs/*`, `05-estimate/*`, `06-review/clashes.md`, `planning-compliance.md`, `cad-issues.md`.

Автоматизация: `tools/clash_check.py` (новый, только чтение) — 9 групп регламента. Скрипт переиспользует `tools/model.py` (геометрия стен D1), `check_electrical_needs.py` (подпроцесс), `calc_sewer_slopes.py` (функции `lines/evaluate`). `gen_furniture.py` не импортируется: при импорте он перезаписывает `furniture.json`/`doors.json`. Его проверки (контур помещения, пересечения, коллекторы, щиты, U22, окна) воспроизведены в режиме только чтения. Существующие скрипты не изменялись. Запуск: `python3 apartment-project/tools/clash_check.py [--json out.json]`, код 1 — есть блокеры.

Критичность: **Блокер** — выпуск комплекта невозможен; **Важно** — исправить до выдачи в производство; **Замечание** — исправить при ближайшей пересборке.
