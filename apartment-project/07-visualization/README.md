## Как эскиз переведён в 3D (трактовки — проверить с заказчиком)

- **Кухня вдоль W3** (слева направо по эскизу): пенал 600 с духовым шкафом и компактной СВЧ, выдвижной модуль 200,
  индукционная панель над ящиками, ящики 600, встроенная ПММ, мойка 600, модуль 200, пенал холодильника 600 + доборная 40.
  На плане навесные шкафы не видны — добавлены по концепции (верх в цвет стены C2, вытяжка встроена в шкаф над индукцией),
  над ними короб-карниз до потолка.
- **Диван 3000** спинкой к кухне, сиденьем к ТВ; **ТВ ≈ 58″** (ширина 1280 по эскизу) на стене W8 над **подвесной консолью**
  (на пол не опирается — водяной тёплый пол, D3).
- **Три смещённых прямоугольника у простенка** — трактованы как раздвижная (телескопическая) стеклянная дверь из трёх
  полотен в тонкой раме «тёмная бронза» C10, собранная в открытом положении.
- **Серый круг вокруг стола** — трактован как раскладной стол Ø1000/1400; показан сложенным (Ø1000), 4 кресла-«корзины».
- Над столом — подвес с опаловым шаром (латунь), на окнах балкона — лёгкие льняные шторы в нише.
- Отделка по концепции: стены C2 «лён» с рамками-молдингами, низ кухни C4 «шалфей» (шейкер, латунные ручки), столешница —
  светлый кварц, фартук — керамогранит «мрамор», пол — дуб ёлочкой (на балконе LVT в тон), балкон — C6 «тёмная олива».
- Свет: утро, солнце с востока-юго-востока (ориентация D25), в интерьере включены споты и подсветка 3000 K.

Это визуализация планировочного решения и цвета, а не замена рабочих чертежей: разделы мебели, электрики, потолков
и смета пока соответствуют варианту D1 (П-диван и проектор на балконе) — их обновление после подтверждения эскиза (D33).

## Пересборка

Нужен модуль Blender `bpy` (Python 3.11) и `shapely`:

```
python3.11 -m venv .venv && .venv/bin/pip install bpy shapely
.venv/bin/python tools/viz_kitchen_balcony.py --views V1,V2,V3,V4,V5 --res 1600x900 --samples 160 \
    --blend 07-visualization/kitchen-balcony.blend
.venv/bin/python tools/viz_kitchen_balcony.py --views V6 --cut --res 1600x900 --samples 128
```

Ракурсы (позиция, цель, фокус) — словарь `CAMS`, размеры мебели — в `build()`.
