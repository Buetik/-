# Дизайн-проект квартиры — рабочая папка агентов ПИБ

Эта папка — общее рабочее пространство команды агентов из `.claude/agents/pib-*.md`.
Запуск всего цикла: команда `/design-project` в Claude Code (см. `.claude/commands/design-project.md`).

## Как начать

1. Положите исходные данные в `01-input/`:
   - план БТИ / поэтажный план (PDF, JPG, DWG/DXF);
   - обмеры (рулетка/лазер) — любым текстом или таблицей;
   - фото помещений, расположение стояков, щита, вентканалов, окон, радиаторов;
   - если у вас есть эталонный проект ПИБ (образец состава/оформления) — положите его в `01-input/pib-reference/`, агенты будут оформлять по нему.
2. Заполните `00-brief/brief.md` (шаблон уже там) или просто ответьте на вопросы агента-ГИПа.
3. Запустите `/design-project`.

## Структура папок

```
00-brief/      бриф, решения заказчика, журнал вопросов (questions.md)
01-input/      исходные данные заказчика (только чтение для агентов, кроме measurements.json)
02-concept/    концепция, палитра, мудборды
03-drawings/   данные разделов (*.json) + готовые листы: dxf/, svg/, pdf/
04-specs/      ведомости и спецификации (md + xlsx)
05-estimate/   смета
06-review/     отчёты нормоконтроля
tools/         общие скрипты отрисовки (создаёт и поддерживает pib-cad)
```

## Единый источник геометрии

Вся геометрия хранится в `01-input/measurements.json` (координаты в мм, начало — левый нижний
угол квартиры по внутренней грани наружной стены, ось X вправо, Y вверх). Все разделы ссылаются
на id стен/помещений из этого файла и пишут свои данные в отдельный слой
`03-drawings/<раздел>.json`. Никто, кроме `pib-measurement`, не меняет существующую геометрию,
а новые перегородки задаёт только `pib-planning` в `03-drawings/planning.json`.

Минимальная схема `measurements.json`:

```json
{
  "units": "mm",
  "ceiling_height": 2700,
  "walls": [{"id": "W1", "a": [0,0], "b": [6200,0], "thickness": 380, "type": "exterior|bearing|partition"}],
  "openings": [{"id": "O1", "wall": "W1", "offset": 1200, "width": 1500, "type": "window|door", "sill": 850, "head": 2350}],
  "rooms": [{"id": "R1", "name": "Кухня-гостиная", "polygon": [[0,0],[6200,0],[6200,4100],[0,4100]]}],
  "utilities": [{"id": "U1", "type": "riser_water|riser_sewer|vent_shaft|el_panel|gas|radiator", "pos": [100,3900]}]
}
```

## Оформление

- СПДС: ГОСТ Р 21.101-2020 (основные надписи, форма 3), ГОСТ 21.501-2018 (АР), ГОСТ 21.607 (ЭО).
- Масштабы: планы 1:50, развертки 1:25–1:50, узлы 1:10.
- Отметки в мм от уровня чистого пола (±0.000 = УЧП).
- Если в `01-input/pib-reference/` лежит образец ПИБ — его оформление имеет приоритет.
