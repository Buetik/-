# Агенты дизайн-проекта квартиры (ПИБ)

| Агент | Раздел |
|---|---|
| `pib-chief-architect` | ГИП: бриф, программа, ведомость листов, общие данные, сборка |
| `pib-measurement` | Обмерный план, единая геометрия `measurements.json` |
| `pib-planning` | Планировочные решения, демонтаж/монтаж, допустимость перепланировки |
| `pib-concept` | Стиль, палитра, материалы, мудборд, ТЗ на визуализацию |
| `pib-furniture` | Расстановка мебели, кухня, двери |
| `pib-electrical` | ЭО/ЭМ: свет, выключатели, розетки, слаботочка, щит |
| `pib-engineering` | ВК/ОВ: сантехника, тёплые полы, отопление, вентиляция, кондиционирование |
| `pib-finishes` | Потолки, полы, развертки, раскладка плитки, узлы |
| `pib-cad` | Чертежи DXF/SVG/PDF со штампом, альбом |
| `pib-specs-estimate` | Ведомости, спецификации, смета |
| `pib-norm-control` | Коллизии, нормы, полнота комплекта |

Запуск всего цикла: `/design-project`. Отдельный этап: `/design-project engineering`.
Рабочая папка: `apartment-project/` (см. её README).
