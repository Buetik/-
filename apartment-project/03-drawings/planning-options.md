# АР. Планировочные решения — варианты A / B / C

Объект: СПб, кв. 108, 1/4 этаж, кирпич 2026 г. Геометрия — `01-input/measurements.json` (координаты, мм).
Данные вариантов: `planning-option-A.json`, `planning-option-B.json`, `planning-option-C.json`.
Превью для заказчика: `svg/planning-option-A.png`, `svg/planning-option-B.png`, `svg/planning-option-C.png`.
Итоговый (рекомендуемый) вариант: `planning.json` — **вариант B [РЕКОМЕНДОВАН]**. Это **[ДОПУЩЕНИЕ]**: заказчик пока не выбрал.

## 0. Общие исходные положения (для всех вариантов)

- **Несущие конструкции.** W7 (стена между комнатами) и W8 (простенки кухни) считаются **несущими** (questions №37; в ОБ-3 ГИП считал их ненесущими — конфликт решён в безопасную сторону). Колонна C1, наружные W1/W2, стены W3–W6 (границы квартиры с соседями и лестничной клеткой) не трогаем. В несущих стенах ничего не пробиваем и не расширяем. Проём O9 только закладывается, в проём O8 только ставится дверь (размер проёма не меняется).
- **Балкон.** В O4 снимается только дверной блок, сам проём 1860 остаётся в прежних границах. Подоконной части у него нет. Простенки 590/1130 и перемычка сохраняются (D2). Контур балкона делается тёплым: тёплое остекление, утепление, электрический тёплый пол (ТП) до уровня ±0.000 кухни, без порога. Водяное отопление на балкон не выводится (D1).
- **Водяной ТП в стяжке.** Стяжку не режем, в пол ничего не крепим (D3). Перегородки из пазогребневых плит (ПГП) ставятся на клей по демпферной ленте, к стенам и потолку крепятся скобами. Мебель крепится к стенам и потолку. Трап душа: низкий, подъём пола санузла +80 (D4).
- **Газа нет** (U20), поэтому правило про газифицированную кухню не применяется. Кухня объединяется только с балконом, а не с жилой комнатой.

## 1. Вариант A — «Минимальное вмешательство»

**Идея.** Все мокрые зоны остаются в существующих границах. Спальня 17,79 изолируется: проём O9 закладывается (NW1), в проём O8 ставится дверь. Гардероб — встроенный шкаф 2480×600 вдоль заложенного проёма. Детская 11,97 отделяется перегородкой NW4 с дверью. Основной санузел 2640×2040: ванна 1700, душ walk-in 900×966 у стояка, инсталляция, раковина 550. Дверь ванной смещается вниз по W12. Постирочная с гостевым WC, дверь O6 застройщика сохраняется.

|---|---|
| Кухня-столовая | 14,20 |
| Спальня (+ шкаф 2480×600 + рабочее место у окна O2) | 17,54 |
| Детская | 11,87 |
| Прихожая-коридор (шкаф 2720×600, коридор 1300) | 9,34 |
| Ванная | 5,39 |
| Постирочная | 3,36 |
| **Итого без балкона** | **61,70** |
| Балкон (тёплый) | 6,80 (после утепления ≈ 6,1) |

**Плюсы:** меньше всего работ и согласований; мокрые зоны в прежних границах; коридор 1300; спальня простой формы.
**Минусы:** ванная на пределе — проходы 650, раковина 550, хранить негде; гардеробной нет (шкаф 2480 — минимум по программе); в постирочной нет высокого шкафа; изголовье кровати у стены, общей с детской.
**Что включить в проект перепланировки:** балкон (O4 + тёплый контур + остекление фасада); закладка O9 в несущей W8; перегородка NW4; перенос двери в W12; перестановка приборов в санузлах (переустройство).

## 2. Вариант B — «Комфортный санузел + гардеробная» [РЕКОМЕНДОВАН]

**Идея.** Ванная расширяется на 290 мм за счёт коридора: стену W12 убираем, новую NW6 ставим левее. Коридор сужается 1300 → 1000 (норма — не менее 850). Ванная получается 2920×2040 = 5,96 м². Спальня 17,79 делится лёгкими перегородками на спальную зону 13,0 м² с двумя окнами и гардеробную 4,2 м² без окна — в бывшей проходной части у кухни. Вход в спальню — через тамбур 900 из существующего проёма O8, в гардеробную ведёт раздвижная дверь. Изголовье кровати ставится к перегородке гардеробной, рабочее место — у окна O2. Детская закрывается перегородкой NW4 с дверью. Постирочная: колонна СМ+СУ, хозмойка, гостевой WC и высокий шкаф; дверь переносится и сужается до 700. Шкаф в прихожей — 3020×600, во всю стену напротив входа.

|---|---|
| Кухня-столовая | 14,20 |
| Спальня (жилая) | 13,03 |
| Гардеробная | 4,17 |
| Детская | 11,87 |
| Прихожая-коридор (шкаф 3020×600, проход 1110, коридор 1000) | 8,67 |
| Ванная | 5,96 |
| Постирочная | 3,36 |
| **Итого без балкона** | **61,26** |

**Плюсы:** в ванной всё по программе с запасом — проходы 650–840, тумба 800, пенал, дверь со стороны прихожей. Полноценная гардеробная (около 5 п.м. хранения). Спальня изолирована от кухни-кинозоны двумя перегородками и тамбуром. Постирочная укомплектована полностью. Шкаф прихожей на всю стену. Несущие конструкции не затрагиваются.
**Минусы:** мокрая зона расширяется за счёт коридора — над нежилым техподпольем, но нужна гидроизоляция и согласование. Коридор 1000. Больше перегородок: дороже A примерно на 150–250 тыс. ₽ (оценка). Жилая площадь по техплану уменьшается до 24,9 м², потому что гардеробная — подсобное помещение. Под полом ванной в полосе 290 мм остаётся участок водяного ТП коридора — его не трогаем и не кладём над ним электрический ТП.
**Что включить в проект перепланировки:** всё перечисленное для A, плюс: перенос стены ванной (W12 → NW6), расширение мокрой зоны (гидроизоляция), перегородки гардеробной NW2/NW3, перенос двери постирочной в W11.

## 3. Вариант C — «Большая детская»

**Идея.** Комнаты меняются местами. Ребёнку — 17,54 м² с двумя окнами: игровая 2×2, ДСК у несущей W7, шкаф 2480. Родителям — 11,87 м²: шкаф 1960×600, рабочее место у W6. Санузел — как в B. Постирочная без WC: максимум хранения, выпуск Ø110 заглушается с доступом для ревизии.

| Помещение | S, м² |
|---|---|
| Кухня-столовая | 14,20 |
| Детская | 17,54 |
| Спальня | 11,87 |
| Прихожая-коридор | 8,67 |
| Ванная | 5,96 |
| Постирочная (без WC) | 3,36 |
| **Итого без балкона** | **61,60** |

**Плюсы:** у ребёнка просторная комната «на вырост»; родители в тихой части квартиры; комфортная ванная; свободная постирочная.
**Минусы:** шкаф родителей 1960 п.м. — меньше программы (2400 п.м. / 1,5 м²); изголовье кровати у стены ванной со стояками (шум); рабочее место не у окна; детская рядом с кинозоной; нет гостевого WC, а сценарий «Утро» из программы на него рассчитан.

Душ остаётся у стояка K1 (U6), чтобы не поднимать пол больше чем на 100 мм. Вентблок U14 трогать нельзя. Отклонённые варианты расширения:
- в сторону прихожей — проход у шкафа стал бы 810 < 850;
- в детскую — мокрая зона над жилой комнатой.

**Почему рекомендован B.** Это единственный вариант, где программа выполнена полностью:
- ванна + душ + WC + раковина с нормальными проходами;
- гардеробная родителей;
- рабочее место у окна;
- полноценная постирочная с гостевым WC;
- шкаф во всю стену прихожей;
- кинозона.

Несущие конструкции при этом не затрагиваются. Цена — коридор 1000 вместо 1300 (по норме достаточно) и дополнительное согласование расширения мокрой зоны над нежилым помещением. Вариант A имеет смысл, если важно минимальное согласование или жилая площадь по документам. Вариант C — если приоритет у детской.
